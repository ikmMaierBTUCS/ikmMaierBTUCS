I am a computational linguist who develops algorithms and turns them into usable tools

**Numeral Grammars**
- [Numeral-Decomposer-1.1](https://github.com/ikmMaierBTUCS/Numeral-Decomposer-1.1) – numeral decomposition algorithm published in a peer-reviewed [paper](https://www.cscjournals.org/library/manuscriptinfo.php?mc=IJCL-142) by the International Journal of Computational Linguistics. Tested in 257 languages.
- [NumberWordGrammarBuilder](https://github.com/ikmMaierBTUCS/NumberWordGrammarBuilder) uses the numeral decomposer as an easy-to-use app to build number word grammars, aimed at speech technology for minority languages

**Board Game: Terra Mystica**
- [Terra-Mystica-Map-Generator](https://github.com/ikmMaierBTUCS/Terra-Mystica-Map-Generator) generates balanced random Terra Mystica Maps. In production on Board Game Arena and in my own [app](https://tm-mapgen.ikmaier.workers.dev/).
- [TM-Neural-Map-Recognizer](https://github.com/ikmMaierBTUCS/TM-Neural-Map-Recognizer): I trained graph convolutional network to distinguish whether a map was generated by my generator or by a dummy version
